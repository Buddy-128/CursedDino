# Cursed Dino
Cursed Dino is a funny game where you fly over and under walls and hope spy (pigeon) does not crash into you.

<img width="1920" height="1080" alt="Cursed dino lol" src="https://github.com/user-attachments/assets/9c433b2b-5726-4bca-b2a9-2fb8de7f182d" />

## Additions in the new codebase
I completly rewrote the codebase to support widescreen displays with fullscreen. The old codebase is avaliable under the tag archive/old.

## Building
I highly do not recommend building the game yourself, but there is a Makefile for Linux with all the dependencies included. Use WSL if you want to compile on Windows.
